The opening
of the Bank.

Road step 10: create the vault collection, initialize SEAL, MINT, BURN and GOV with the ruled values, create the three cbBTC accounts, and fund the revenue address. Only the launch key can use this page.

Every value is written once and can never be corrected. Each step shows its values in plain words, runs a dry run, asks for your signature, then re-reads the chain and stops for good if anything differs from the ruling.

Road step 9 (deploying and checking the audited program bytes) is done before this, by the command line, and this page checks its result before anything else. Road step 11 (removing the upgrade authority, which makes the programs final) comes after this ceremony.
